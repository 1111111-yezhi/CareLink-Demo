【如何打开】
1. 解压本压缩包到任意目录（路径含中文也没关系）
2. 双击 index.html，用 Chrome / Edge 等现代浏览器打开
3. 无需安装任何软件、无需联网、无需账号密码
   依赖的样式、图标与图表资源已全部放在 vendor/ 目录内，可完全离线运行

【建议查看方式】
把浏览器窗口调成手机尺寸（约 390 × 850）观感最佳；
在电脑上可按 F12 打开开发者工具，切换到手机模拟视图。

  index.html              原型导览（入口页）

────────────────────────────────────────
【重点看什么】

· agent_demo.html —— 点击「播放调度过程」，可依次看到编排智能体意图分解
  → 5 个专业智能体调度（含各自耗时）→ 结果融合的完整过程。
  4 个预设场景：头晕不适 / 用药咨询 / 跌倒告警 / 思念家人。
  凡涉及医学结论的智能体输出，下方均标注了知识库来源；纯情感支持与
  家属通知类输出则不引用医学结论，刻意留空。

· elder_sos.html —— 按下红色求助按钮，可看到「安全级」事件如何启动一级
  响应，并随时间逐级升级到社区医生与 120。

· 老人端与家属端的数据是相互对应的：同一位老人「李奶奶」、同一时段
  （2026-09-29 08:20 前后）的体征、用药与预警记录，可在两端交叉核对。

────────────────────────────────────────
【说明】
本原型为纯前端高保真原型，用于验证交互流程与多智能体协同机制。
页面中的体征数值、人名、日期、地址均为演示用示例数据；
后端编排引擎（LangChain / FastAPI / Milvus 等）正在开发中。
界面标注「不构成医疗诊断」，产品定位为健康提醒与陪伴。
